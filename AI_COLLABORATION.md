## How AI Was Used

### Code Generation

- **Backend Services**: Implemented `services/face_detector.py` using YOLOv8-face for face detection
- **API Endpoints**: Created REST endpoints in `api/` for video ingestion and ROI retrieval
- **WebSocket Handler**: Built real-time video streaming in `api/video_ws.py`
- **Database Models**: Defined SQLAlchemy models in `db/models.py`
- **ROI Drawing**: Implemented Pillow-based ROI rendering in `utils/draw.py`

### Frontend Development

- **VideoStream Component**: Built WebRTC video capture with WebSocket streaming
- **ROI Overlay**: Implemented EMA smoothing (0.15 factor), coordinate scaling, and 20% box padding
- **Page Layout**: Created main UI with Next.js App Router
- **UI Components**: Built Button component

### Configuration & DevOps

- **Backend Dockerfile**: Configured Python 3.11-slim with CUDA-enabled PyTorch (cu124)
- **Frontend Dockerfile**: Configured Next.js production build
- **docker-compose.yml**: Added GPU device reservation for NVIDIA Container Toolkit
- **CI Workflow**: Created GitHub Actions workflow (`.github/workflows/ci.yml`)

### Documentation

- **README.md**: Comprehensive project documentation with architecture diagram
- **AI_COLLABORATION.md**: This report documenting AI collaboration
- **Frontend README.md**: Frontend-specific documentation

### Debugging & Refactoring

- **Model Selection**: Switched from `yolov8n.pt` (person detection) to `yolov8n-face.pt`
- **Docker Fixes**: Fixed CPU-only torch, corrected model filename, removed unused dependencies
- **Test Fixes**: Updated test assertions to use internal `_model` attribute

## Human Oversight

- **Code Review**: All AI-generated code was reviewed by the human developer
- **Architecture Decisions**: Key decisions (e.g., no OpenCV, Pillow for ROI drawing) were human-directed
- **Testing**: Manual testing performed to validate face detection, API endpoints, and WebSocket streaming
- **Security**: Environment-based CORS implementation reviewed by human

## Limitations & Notes

- **PyTorch CUDA**: Used CUDA 12.4 (cu124) for forward compatibility with CUDA 13.2 driver
- **Model Download**: YOLOv8n-face model auto-downloads on first run (~6.2 MB)
- **Single Face**: Project assumes only one face per frame (per PRD requirement)
- **Local Dev vs Docker**: Local development uses GPU; Docker requires NVIDIA Container Toolkit for GPU support
